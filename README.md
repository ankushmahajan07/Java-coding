Password Validation
This task validates passwords based on a few simple rules using Java.  
It follows a modular, interface-based design and includes unit tests.

Rules
1. Password should be longer than 8 characters  
2. Should not be null  
3. Should contain at least one uppercase letter  
4. Should contain at least one lowercase letter  
5. Should contain at least one number  

Password is **OK** if at least 3 conditions are true,  
but **never OK** if it fails the length rule.

---
How to Run
In IntelliJ
1. Open the project in IntelliJ  
2. Run the `Main.java` file.
